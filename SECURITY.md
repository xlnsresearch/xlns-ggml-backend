# Security Policy

This is research code: LNS backends for ggml and llama.cpp, built from
source. There are no releases, so only the latest `main` is supported.

## Reporting a vulnerability

Please don't open a public issue for a security problem. Report it privately
through the repository's **Security** tab, using **Report a vulnerability**.
If that option is not available, contact the maintainer,
[markgarnold](https://github.com/markgarnold), directly.

Include what you found, the commit you tested, and the steps or input that
trigger it. You should get a reply within a couple of weeks.

Problems in ggml or llama.cpp themselves should go to those projects:
[ggml](https://github.com/ggml-org/ggml/security) and
[llama.cpp](https://github.com/ggml-org/llama.cpp/security).
